# Referencia

Acá van los datos que se consultan pero no se discuten: números, tablas, precios,
fechas, links a fuentes externas.

Criterio para decidir si algo va acá o en `10-contexto/`: si el dato puede quedar
obsoleto por sí solo con el paso del tiempo, va acá y lleva la fecha de la fuente
en el cuerpo de la nota.
